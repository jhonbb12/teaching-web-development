# Backlog do projeto Minecraft

> A equipe adaptou as histórias para uma página humorística sobre encontrar uma forma segura de jogar Minecraft.

## P1 — Entender a proposta da aventura

**Como** jogador, **quero** entender a proposta da página **para** descobrir como começar minha aventura sem cair em uma caverna suspeita da internet.

**Critério observável:** o título e a descrição explicam a proposta com clareza e aparecem sem erros.

## P2 — Encontrar um caminho seguro

**Como** jogador, **quero** encontrar uma orientação sobre o acesso ao jogo **para** evitar links duvidosos e creepers digitais.

**Critério observável:** a página apresenta uma chamada clara para conhecer a proposta.

## P3 — Confirmar a missão

**Como** jogador, **quero** receber uma mensagem depois do clique **para** saber que minha missão foi registrada e que nenhum zumbi apertou o botão por mim.

**Critério observável:** o texto de status muda após o clique, confirmando a interação.
